# Mixbee Studio

A cinematic, responsive studio website built with Next.js, React, TypeScript and React Three Fiber.

## Run locally

1. Install Node.js 20 or newer.
2. Clone this repository.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open http://localhost:3000.

## Current build

- Responsive public homepage
- Animated 3D microphone hero
- Studio, services, gallery and contact sections
- Temporary typography-based Mixbee identity
- Placeholder visuals that can be replaced with approved studio photos
